# IEEE conference paper source scaffold

`main.tex` is a structure and figure scaffold, **not a submission-ready paper**. The Phase 2 brief explicitly requires the assessed paper to be written by the group member in their own words and prohibits AI-generated writing. Fazal must write or rewrite all prose, including the title and figure/table captions, verify every citation and result, and fill the required 8–10 pages. The email should also be checked. The 30 DOI-verified entries in `references.bib` are research leads; cite only works actually discussed, and ensure every cited source appears in the bibliography.

The folder includes the [CTAN IEEEtran](https://ctan.org/pkg/ieeetran) class and BibTeX style under LPPL 1.3, so it compiles locally and imports into Overleaf. `architecture.dot` is the editable source of `architecture.png`; `diagnosis_macro_f1.png` is generated by `python3 -m experiments.diagnostic_ci` from saved results. Table numbers are generated with `python3 -m experiments.build_paper_tables` after the repair run completes. All captions remain marked for Fazal to write.

After writing and finalizing the manuscript, run this from the repository root:

```bash
python3 paper/finalize_submission.py
```

The helper checks the 150–250 word abstract, placeholder captions, LaTeX build, 25–30 cited references, and 8–10 page count. It creates the correctly named paper PDF and source ZIP in `submission/` only after those checks pass. Review all claims, citations, figures, format, and originality yourself. Run both Turnitin reports on that **same final PDF** through the university service and save them under the exact Phase 2 filenames.
